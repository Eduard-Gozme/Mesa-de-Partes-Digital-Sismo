# Mesa de Partes Digital–Sismo (Ate)

## Descripción
Prototipo académico desarrollado en Python para registrar, buscar y organizar solicitudes ciudadanas relacionadas con un posible sismo en el distrito de Ate, Lima.

## Objetivo
Facilitar el registro de reportes de daños, solicitudes de ayuda y solicitudes de atención, asignando una prioridad según la información proporcionada.

## Funciones principales
- Registrar expedientes con un código.
- Validar los datos ingresados.
- Clasificar solicitudes en CRÍTICO, ALTO, MEDIO o BAJO.
- Buscar expedientes por código.
- Ordenar expedientes según su prioridad.
- Mostrar un listado y un resumen.
- Guardar los registros en un archivo TXT.

## Archivos del programa
- `main.py`: menú principal.
- `validaciones.py`: validación de los datos.
- `clasificacion.py`: cálculo de prioridades.
- `expedientes.py`: registro, búsqueda y ordenamiento.
- `archivos.py`: almacenamiento y recuperación de registros.

## Cómo ejecutar
1. Tener Python instalado.
2. Descargar los cinco archivos `.py` en una misma carpeta.
3. Abrir una terminal en esa carpeta.
4. Ejecutar `python main.py`.
5. Seleccionar una opción del menú.

## Alcance
Es un prototipo educativo desarrollado para Fundamentos de Programación. No representa un sistema oficial de la Municipalidad de Ate ni está conectado a sus servicios.
